PARA USAR NO SEU PROJETO

Uma API simples.
Pronta para consultar.

Todos os endpoints são públicos e aceitam GET. As consultas retornam JSON e permitem acesso de outras origens via CORS.

Abrir especificação OpenAPI ↗
GET/api/filosofosLista, busca e paginação ↗ GET/api/filosofos/:idOuSlugDetalhes de um filósofo ↗ GET/api/correntesCorrentes disponíveis ↗ GET/api/statusDisponibilidade da API ↗

Exemplo com JavaScript

const resposta = await fetch(
  '/api/filosofos?q=kant&limite=5'
);
if (!resposta.ok) throw new Error('Falha na consulta');
const { dados, paginacao } = await resposta.json();

Em outro site, use o domínio desta API antes de /api.

Parâmetros de consulta

Parâmetros aceitos por GET /api/filosofos
ParâmetroO que fazPadrão
qBusca no nome, descrição e correntes. Até 200 caracteres.Todos
correnteFiltra pelo nome completo de uma corrente.Todas
paginaNúmero da página, de 1 a 1.000.000.1
limiteResultados por página, de 1 a 100.20

Os resultados seguem a ordem alfabética. A busca ignora acentos e maiúsculas; vários termos devem estar presentes. Consultas sem resultados retornam uma lista vazia. Parâmetros inválidos retornam 400; um ID ou slug inexistente retorna 404.
